## 💻 Programs

This repository contains **16 practical programs** based on polymorphism and related Object-Oriented Programming concepts in C++.

### 01. Function Overloading

Demonstrates compile-time polymorphism using multiple functions with the same name but different parameter lists.

### 02. Area Calculator Using Function Overloading

Demonstrates function overloading to calculate the areas of different shapes using different parameters.

### 03. Unary Minus Operator Overloading

Demonstrates unary operator overloading by overloading the minus (`-`) operator for a user-defined class.

### 04. Prefix and Postfix Increment Operator Overloading

Demonstrates prefix and postfix increment operators and their different behaviors.

### 05. Binary + Operator Overloading

Demonstrates binary operator overloading by adding two complex numbers using the `+` operator.

### 06. Relational Operator Overloading

Demonstrates relational operator overloading by comparing two user-defined objects using the `>` operator.

### 07. Friend / Non-Member Operator Overloading

Demonstrates operator overloading using a friend non-member function.

### 08. Base Pointer Without Virtual Function

Demonstrates static binding using a base-class pointer when the base function is not virtual.

### 09. Base Pointer With Virtual Function

Demonstrates run-time polymorphism using a base-class pointer and virtual functions.

### 10. Base Reference With Virtual Function

Demonstrates dynamic binding using a base-class reference and virtual functions.

### 11. Abstract Class and Pure Virtual Function

Demonstrates an abstract class using a pure virtual function and derived classes.

### 12. Collection of Polymorphic Shape Pointers

Demonstrates polymorphic processing of different derived shape objects through a common base-class interface.

### 13. Virtual Destructor

Demonstrates the use of a virtual destructor for safe destruction of derived objects through a base-class pointer.

### 14. Object Slicing

Demonstrates object slicing when a derived object is passed by value as a base-class object and shows how references and pointers avoid slicing.

### 15. Payment Processing System

Implements a real-world payment processing system using an abstract base class, pure virtual functions and run-time polymorphism.

### 16. Employee Payroll System

Implements an employee payroll system using an abstract base class, inheritance, virtual functions and run-time polymorphism.
